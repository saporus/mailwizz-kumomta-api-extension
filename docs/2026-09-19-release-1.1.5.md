# Release 1.1.5 reconciliation

The public 1.1.4 ZIP omitted later changes already installed in production, and the live bootstrap still declared 1.1.3. This release packages the existing shared cooldown, memory/concurrency retry distinction, connection-failure handling, interactive error display and delivery-report acceptance clarification. The API model and cooldown helper were reconciled against the deployed files and the previously pushed Kumo UI integration source. No admission cutoff, provider rate, hold or campaign setting is changed.
